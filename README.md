#  Vôlei Club System

Sistema de gestão de time de vôlei com:

- Login de usuários
- Gestão de atletas
- Controle de mensalidades
- Pagamentos online
- Painel administrativo

---

##  Tecnologias

### Frontend
- React (Vite)
- React Router
- Axios

### Backend
- Spring Boot
- Spring Security + JWT
- JPA/Hibernate

### Banco de Dados
- MySQL (Railway)
